# Changelog

## 1.0.0 (2026-10-24)

First official release of the SaRiGaMaParishath Android app (package `com.sarigamaparishath.app`, version code 1).

- Home with today's sankalpam and sunrise and sunset below the logo.
- Activities, Events, Gallery and Blog from the Parishath website.
- Donate through Razorpay, with donation stats, recent donations and FAQ.
- Website menu: About, Guruvu garu, Books (with Razorpay), Testimonials, FAQ, Contact and Newsletter.
- Login by mobile number or email, Register, first-login setup, forgot password with a one-time code, change password, and email confirmation messages.
- My Profile.

The APK attached to the GitHub release v1.0.0 is signed with the standard debug key, fine for sharing with members directly. A Play Store release needs its own signing key.
